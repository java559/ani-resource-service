## 本轮行为

- Network 原 worker 在可用 Subnet 的正常周期内为真实租户 namespace 准备受管 NAD/SA。管理意图先写入 migration 0019 的租户复合关系，再固定 Namespace/NAD/SA UID；新租户不依赖逐条部署映射。读解析无写入，UID 漂移拒绝，辅助失败不改变普通 Subnet 可用性，保留旧冻结静态映射兼容。
- 创建 DNS 支持平台默认或自定义；新建冻结有效 DNS，原生 VM 显式 dnsPolicy=None。GetDNSDefaults 为只读、受信租户接口；旧无 DNS 的冻结规格与摘要保持。Gov HTTP 入口按原授权/套餐及持久受理规则接入。
